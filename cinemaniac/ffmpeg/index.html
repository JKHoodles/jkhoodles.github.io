Rebuilding and replacing the libraries

On a Mac with Xcode, put build-ffmpeg.sh in a Scripts/ folder and the FFmpeg tarball in Vendor/FFmpeg/src/ next to it, then run Scripts/build-ffmpeg.sh. It produces one dynamic .xcframework per library.

The libraries ship as separate dynamic frameworks inside CineManiac.app/Frameworks/, loaded at run time. A modified build with the same public interface can replace them there; the app must then be re-signed to install it on a device, as for any iOS app.
