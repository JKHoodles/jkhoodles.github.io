libsmb2 Source Code

For CineManiac 1.0 · libsmb2 6.3

CineManiac uses libsmb2 by Ronnie Sahlberg, version 6.3, to play videos from SMB file sharing (Mac, Windows and NAS shared folders). The library is licensed under the GNU Lesser General Public License version 2.1 or later, and its DCE/RPC parts under the BSD 2-Clause licence. The libsmb2 source is unmodified.

  • build-libsmb2.sh: the exact script that compiles and packages the library. Kerberos support is left out, and the public headers' include paths are rewritten for framework packaging.
  • LIBSMB2_BUILD_INFO.md: the version and toolchain used for the shipped build.
  • LICENCE-LGPL-2.1.txt and COPYING: the licences, and which parts each covers.
  • README.md: how to rebuild the library and replace it.

Rebuilding and replacing the library

On a Mac with Xcode, put build-libsmb2.sh in a Scripts/ folder and the libsmb2 tarball in Vendor/libsmb2/src/ next to it, then run Scripts/build-libsmb2.sh. It produces libsmb2.xcframework.

The library ships as a separate dynamic framework, CineManiac.app/Frameworks/libsmb2.framework, loaded at run time. A modified build with the same public interface can replace it there; the app must then be re-signed to install it on a device, as for any iOS app.
